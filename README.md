CorePit website

Source repository for the public website of CorePit, the game previously named BallPit.

Local game project: ../BallPit-5/ when the website and game are checked out beside each other.

This website is maintained as an independent Git repository. Run website Git commands from this directory. Clone and manage the website and game repositories separately.

Keep website builds self-contained. Copy approved screenshots, video, and other website assets into this repository. Do not depend on files outside this directory for deployment, and do not copy Unity source or third-party assets wholesale.

No website implementation or hosting configuration has been added yet.
